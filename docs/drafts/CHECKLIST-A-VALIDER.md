# Checklist à valider — cluster douane RDC (brouillons)

Document de travail pour Andy et Vero. Il reprend, une ligne par point, tout ce
qui est marqué **[À VÉRIFIER]** dans les deux brouillons de `docs/drafts/`
(`dedouanement-rdc.fr.md` / `.en.md` et `documents-douane-rdc.fr.md` / `.en.md`).

Rien n'est inventé ici : chaque ligne reprend un point déjà présent dans un
brouillon. La colonne « Source officielle trouvée » indique la source utilisée
pendant la recherche quand il y en a une ; « — » signifie qu'aucune source
officielle n'a été trouvée et que la réponse doit venir de vous (ou d'une source
officielle à confirmer). Les versions FR et EN d'un même brouillon portent les
mêmes points.

**Comment l'utiliser :** remplissez la colonne « Réponse d'Andy / Vero ». Une
fois tous les points tranchés, le brouillon pourra être corrigé puis publié via
`/admin/blog`. Tant qu'un point reste ouvert, ne publiez pas l'affirmation
correspondante.

Ce fichier n'est relié à aucune page du site.
